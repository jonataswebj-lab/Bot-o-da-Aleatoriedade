# 🎲 Botão da Aleatoriedade

Página interativa em que cada clique no botão sorteia um efeito diferente: cores, tamanhos, mensagens e até eventos secretos que aparecem conforme o número de cliques.

🔗 **[Ver site no ar](COLE-AQUI-O-LINK-DO-SITE)**

![Prévia do projeto](COLE-AQUI-O-PRINT)

## O que acontece ao clicar?
- Um contador mostra quantos cliques já foram dados
- A cada clique, o código sorteia um efeito: troca a cor do fundo, muda a cor ou o tamanho do botão, ou mostra uma mensagem aleatória
- Em certos números de cliques, acontecem **eventos secretos**. Descubra clicando 😉

## O que pratiquei
- Manipulação do DOM (`querySelector`, `style`, `innerText`)
- Eventos de clique e de movimento do mouse (`addEventListener`)
- Números aleatórios com `Math.random()` e `Math.floor()`
- Condicionais (`if`) e contador de estado
- Animações com `@keyframes` no CSS
